## Supperb — Full Stack Developer Intern

During my internship at Supperb, I worked as a Full Stack Developer, contributing to the development of a production-ready web application focused on connecting users through a seamless and intuitive digital experience.

- Developed and maintained both frontend and backend features of the application  
- Built responsive and scalable user interfaces with a strong focus on usability and performance  
- Designed and integrated RESTful APIs for dynamic data handling  
- Managed database operations, ensuring efficient data storage and retrieval  
- Collaborated on implementing core platform features for user interaction and workflow management  
- Ensured clean code practices, modular architecture, and maintainability across the codebase  

### Tech Stack

- **Frontend:** React.js, TypeScript, Next.js  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Styling:** Tailwind CSS  
- **Tools:** GitHub, Vercel  

### Key Achievements

- Contributed to building a fully functional, production-level application  
- Developed reusable components and backend modules to improve development efficiency  
- Enhanced application performance and optimized API responses  
- Strengthened end-to-end development skills across the full stack  

### What I Learned

This experience gave me hands-on exposure to real-world full stack development. I learned how to design scalable systems, manage data flow between frontend and backend, and build applications that are both efficient and user-centric.

It also improved my ability to work on complex features, debug issues effectively, and deliver reliable solutions in a production environment.
